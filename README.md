# Box メタデータビューア (make_boxpages)

Boxフォルダ内のファイル一覧と、それぞれのファイルに付加されたメタデータを取得してリスト表示するWebアプリケーションです。

---

## 🌟 主な機能

- **メタデータ自動リスト表示**:
  フォルダ内のアイテム一覧とメタデータを動的に読み込み、「ファイル名」「メタデータ1」「メタデータ2」... の表形式で一覧表示。
- **インクリメンタル検索**:
  ファイル名やメタデータ値によるリアルタイム絞り込み。
- **CSVダウンロード**:
  表示中のメタデータ一覧を UTF-8 (BOM付き) CSV でエクスポート。
- **ローカル自動保存**:
  一度入力した開発者トークンとフォルダIDをブラウザのローカルストレージに保持。
- **デモモード**:
  Boxの接続設定前でも画面の動作や表示イメージを即座に確認可能。

---

## 🚀 クイックスタート

### 1. サーバーを起動
プロジェクトフォルダで以下のコマンドを実行します：

```powershell
python serve.py
```

自動的にブラウザで `http://localhost:8000` が開きます。

---

## 🔑 Box API の準備手順 (開発者トークン & CORS設定)

ブラウザからBox APIを直接呼び出すため、以下の2点の設定を行います。

### 1. Box Developer Console でアプリを作成
1. [Box Developer Console](https://app.box.com/developers/console) にアクセスしてログイン
2. **「アプリの新規作成」** ➔ **「カスタムアプリ」** を選択
3. アプリケーション名（例: `MetadataViewer`）を入力し、認証方法で「**ユーザー認証 (OAuth 2.0)**」を選択して作成

### 2. CORSドメインの追加 (★最重要)
1. 作成したアプリの **「構成」** タブを開く
2. 下部にある **「CORSドメイン」** 欄に以下を追加して **「変更を保存」** をクリック：
   ```text
   http://localhost:8000
   ```
   *(※ これが未設定の場合、ブラウザのセキュリティ制限によりAPI通信がブロックされます)*

### 3. 開発者トークンを発行
1. 「構成」タブ内の **「開発者トークン」** セクションへ移動
2. **「開発者トークンを生成」** をクリックしてトークンをコピー（有効期間: 1時間）

---

## 💻 使い方

1. ブラウザ画面上の入力欄に **開発者トークン** を貼り付けます。
2. 対象の **フォルダID**（またはBoxのフォルダURL `https://app.box.com/folder/123456...`）を入力します。
3. **「メタデータを取得」** をクリックすると、フォルダ内のファイルとメタデータ一覧が表示されます。
